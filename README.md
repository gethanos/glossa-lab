# GlossaLab: ΓΛΩΣΣΑ, εργαστήριο προγραμματισμού

[![CI](https://github.com/gethanos/glossa-lab/actions/workflows/ci.yml/badge.svg)](https://github.com/gethanos/glossa-lab/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Εκπαιδευτικός διερμηνευτής της **ΓΛΩΣΣΑΣ** (Γ΄ Λυκείου) και της **ψευδογλώσσας** (Β΄ και Γ΄ Λυκείου) για το μάθημα της Πληροφορικής του Γενικού Λυκείου.
Τρέχει εξ ολοκλήρου στον browser, χωρίς εγκατάσταση και χωρίς server, και έχει σχεδιαστεί
ώστε ο μαθητής να **βλέπει** τι κάνει το πρόγραμμά του και να **καταλαβαίνει** γιατί κάνει λάθος.

**Online:** https://vle.cited.gr/apps/glossa-lab/ (μαζί με άλλες εφαρμογές στο [vle.cited.gr/apps](https://vle.cited.gr/apps))

## Δυνατότητες

- **Δύο γλώσσες:** ΓΛΩΣΣΑ και ψευδογλώσσα, με διακόπτη στην κεφαλίδα του κώδικα και ξεχωριστό πρόχειρο για καθεμία. Ο σύνδεσμος `…/glossa-lab/#psevdoglossa` ανοίγει απευθείας στην ψευδογλώσσα (`#glossa` στη ΓΛΩΣΣΑ). Αν ο κώδικας είναι γραμμένος στην άλλη γλώσσα, η εφαρμογή το επισημαίνει και προσφέρει μεταφορά.
- **Βηματική εκτέλεση:** βήμα, βήμα πάνω από κλήση, έξοδος από υποπρόγραμμα, αυτόματη εκτέλεση με ρυθμιζόμενη ταχύτητα, σημεία διακοπής.
- **Εξήγηση κάθε βήματος** σε φυσική γλώσσα, με την αλυσίδα υπολογισμού: `Σ + Α[i] → 10 + 4 → 14`.
- **Μνήμη:** κάθε μεταβλητή ως κουτί με τον τύπο της, κάθε πίνακας ως σειρά ή πλέγμα κελιών· ό,τι αλλάζει ή διαβάζεται επισημαίνεται.
- **Στοίβα και ουρά:** ένας μονοδιάστατος πίνακας εμφανίζεται ως στοίβα (κατακόρυφα, με τον δείκτη `top`) ή ως ουρά (με τους δείκτες `front` και `rear`). Η αναγνώριση γίνεται αυτόματα από τα ονόματα της θεωρίας (`top`/`κορυφή`, `front`/`εμπρός`, `rear`/`πίσω`) ή με επιλογή από την κεφαλίδα του πίνακα. Οι θέσεις έξω από τη δομή φαίνονται αχνές, ώστε να φαίνεται ότι η απώθηση/εξαγωγή δεν σβήνει την τιμή από τον πίνακα. Επισημαίνεται πότε η δομή είναι άδεια ή γεμάτη (υποχείλιση/υπερχείλιση στην επόμενη λειτουργία).
- **Βρόχοι και κλήσεις:** τιμές του μετρητή του ΓΙΑ, αποτέλεσμα κάθε ελέγχου συνθήκης, πλήθος επαναλήψεων, στοίβα κλήσεων.
- **Πίνακας τιμών** όπως συμπληρώνεται στο τετράδιο.
- **Αναλυτικά μηνύματα λαθών:** τι σημαίνει το λάθος, πώς διορθώνεται, παράδειγμα σωστού κώδικα, προτάσεις «μήπως εννοούσες». Εντοπίζονται συχνά λάθη μαθητών, όπως `x = 5` αντί για `<-`, `ΤΕΛΟΣ ΑΝ` με κενό, `x > 0 ΚΑΙ < 10`, ακέραια μεταβλητή που παίρνει αποτέλεσμα της `/`, αθροιστής χωρίς αρχική τιμή, δείκτης εκτός ορίων, ατέρμονες βρόχοι.
- **Επεξεργαστής:** χρωματισμός σύνταξης, αυτόματη συμπλήρωση λέξεων, μεταβλητών και ολόκληρων δομών, αυτόματη στοίχιση, έλεγχος λαθών κατά την πληκτρολόγηση, μεγιστοποίηση, άνοιγμα και αποθήκευση αρχείων.
- **Οδηγός γλώσσας** με παραδείγματα που εισάγονται στον κώδικα με ένα κλικ.
- Φωτεινό και σκοτεινό θέμα, πλήρης λειτουργία σε κινητά και tablet.

## Γρήγορη εκκίνηση

| Θέλω να… | Κάνω… |
| --- | --- |
| το χρησιμοποιήσω | ανοίγω τη [σελίδα online](https://vle.cited.gr/apps/glossa-lab/) ή το `dist/index.html` μετά το build |
| το φτιάξω τοπικά | `npm install` και `npm run build` → φάκελος `dist/` |
| αναπτύξω χωρίς build | `npx serve src` (ή `python3 -m http.server -d src`) και άνοιγμα του `index.html` |
| τρέξω τους ελέγχους | `npm test` |

Το `dist/index.html` είναι αυτοτελές αρχείο: μπορεί να μοιραστεί μόνο του, να ανέβει σε ηλεκτρονική τάξη (π.χ. Moodle) ή να ανοίξει από USB. **Δεν κάνει καμία εξωτερική κλήση:** οι γραμματοσειρές είναι ενσωματωμένες και τίποτα δεν στέλνεται εκτός του browser του χρήστη.

## Εγκατάσταση σε web server

Το `npm run build` δημιουργεί τον φάκελο `dist/`, που ανεβαίνει **ολόκληρος** στο `/apps/glossa-lab/`:

| Αρχείο | Ρόλος |
| --- | --- |
| `index.html` | η εφαρμογή, αυτοτελής (κώδικας, στυλ, γραμματοσειρές ενσωματωμένα) |
| `site.webmanifest` | εγκατάσταση στην αρχική οθόνη κινητού ή ως εφαρμογή υπολογιστή |
| `favicon-32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | εικονίδια για browsers, iOS και Android |
| `social-preview.png` | εικόνα κοινοποίησης (Open Graph / Twitter) |

Παράδειγμα για nginx:

```nginx
location = /apps/glossa-lab { return 301 /apps/glossa-lab/; }

location /apps/glossa-lab/ {
    try_files $uri $uri/index.html =404;

    add_header Content-Security-Policy "default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; font-src data:; img-src 'self' data:; manifest-src 'self'; connect-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'self'" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;
    add_header Permissions-Policy "camera=(), microphone=(), geolocation=()" always;
    add_header Cache-Control "no-cache" always;
}
```

- Το `connect-src 'none'` απαγορεύει στη σελίδα κάθε αίτημα δικτύου. Αυτό έχει σημασία όταν η εφαρμογή μοιράζεται το ίδιο domain με άλλες εφαρμογές ή με πλατφόρμα όπως το Moodle. Τα δεδομένα του browser (`localStorage`) έχουν το πρόθεμα `glossa-lab:`.
- Το `img-src 'self'` και το `manifest-src 'self'` χρειάζονται για τα εικονίδια και το manifest.
- Η ανακατεύθυνση χωρίς την τελική κάθετο κρατά μία μόνο διεύθυνση για τις μηχανές αναζήτησης, ίδια με το `canonical`.

## Επέκταση

- **Νέο μήνυμα λάθους:** εγγραφή στο `CATALOG` του `core/errors.js` και `throw new GlossaError('ΚΩΔΙΚΟΣ', θέση, παράμετροι)` εκεί που εντοπίζεται.
- **Νέα ενσωματωμένη συνάρτηση:** εγγραφή στο `FUNCTIONS` και στους πίνακες των γλωσσών στο `core/builtins.js`, και τεκμηρίωση στο `ui/editor/snippets.js`.
- **Νέα εντολή:** λέξη στο `core/dialects.js`, μέθοδος `parseX` στον κοινό parser, έλεγχος στους δύο αναλυτές, εκτέλεση στο `Interpreter.statement`. Κάθε `yield this.pause(line)` είναι σημείο όπου μπορεί να σταματήσει η βηματική εκτέλεση· κάθε ζεύγος `begin()`/`act()` γράφει μία γραμμή στον πίνακα τιμών και την εξήγηση του βήματος.
- **Νέο πρότυπο κώδικα:** εγγραφή στον πίνακα της γλώσσας στο `ui/editor/snippets.js` (εμφανίζεται στη συμπλήρωση και στον οδηγό).
- **Νέο παράδειγμα:** εγγραφή στο `src/examples.js` και η αναμενόμενη έξοδός του στο `test/examples.test.mjs`.

Οδηγίες για συνεισφορές στο [CONTRIBUTING.md](CONTRIBUTING.md).

## Επιλογές σημασιολογίας

Οι κανόνες ακολουθούν το θεωρητικό μέρος των βιβλίων: «Εισαγωγή στις Αρχές της Επιστήμης των Η/Υ» (Β΄ Λυκείου), «Ανάπτυξη Εφαρμογών σε Προγραμματιστικό Περιβάλλον» και το Συμπληρωματικό εκπαιδευτικό υλικό (Γ΄ Λυκείου). Όπου η θεωρία δεν ορίζει κάτι, η επιλογή αναφέρεται εδώ.

**Και στις δύο γλώσσες**
- Κεφαλαία/πεζά και τόνοι αγνοούνται σε λέξεις-κλειδιά και ονόματα (`Άθροισμα` = `ΑΘΡΟΙΣΜΑ`).
- Στα `ΚΑΙ` / `Η` υπολογίζονται και τα δύο μέλη.
- `Α_Μ` αποκόπτει προς το μηδέν: `Α_Μ(-2.5) = -2`.
- Μετά από ένα βρόχο Για ο μετρητής έχει την πρώτη τιμή που δεν ικανοποίησε τη συνθήκη (π.χ. 11 για 1..10).
- Τα λάθη ομαδοποιούνται όπως στο Συμπληρωματικό υλικό: συντακτικά, αντικανονικού τερματισμού, και προειδοποιήσεις για πιθανά λογικά λάθη.

**ΓΛΩΣΣΑ**
- Κείμενο σε απλά εισαγωγικά (και οι τυπογραφικές μορφές τους `‘…’`), πραγματικοί με τελεία.
- Οι συγκρίσεις κειμένων (`=`, `<>`, `<`, `>`, `<=`, `>=`, `ΕΠΙΛΕΞΕ`) ακολουθούν την ελληνική αλφαβητική σειρά: αγνοούνται πεζά/κεφαλαία και τόνοι/διαλυτικά, και το `ς` θεωρείται ίδιο με το `σ`. Οι υπόλοιποι χαρακτήρες συγκρίνονται όπως είναι. Η κανονικοποίηση γίνεται μόνο κατά τη σύγκριση· οι τιμές των μεταβλητών δεν αλλάζουν. Είναι σχεδιαστική επιλογή του GlossaLab, όχι ρητός κανόνας του σχολικού βιβλίου.
- Στην εκχώρηση και στις παραμέτρους η τιμή είναι του ιδίου τύπου με τη μεταβλητή. Το `ΔΙΑΒΑΣΕ` και ο μετρητής του `ΓΙΑ` δέχονται ακέραιο σε πραγματική μεταβλητή.
- Το `ΜΕ ΒΗΜΑ` γράφεται και με κενό (όπως στη σύνταξη του ΓΙΑ) και με κάτω παύλα.
- Το ίδιο όνομα δεν μπορεί να είναι μετρητής εμφωλευμένων `ΓΙΑ`· η αλλαγή του μετρητή μέσα στο σώμα βγάζει προειδοποίηση.
- `DIV` / `MOD` με αρνητικούς: αποκοπή προς το μηδέν, το υπόλοιπο έχει το πρόσημο του διαιρετέου.
- Οι συναρτήσεις παίρνουν τιμές· οι διαδικασίες επιστρέφουν τις αλλαγές των παραμέτρων στον καλούντα. Δεν υπάρχουν καθολικές μεταβλητές.

**Ψευδογλώσσα**
- Οι μεταβλητές δεν δηλώνονται· το είδος τους (αριθμητική, αλφαριθμητική, λογική) ορίζεται από την τιμή. Οι πίνακες δεν έχουν μέγεθος· οι θέσεις αριθμούνται από το 1.
- Κείμενο σε διπλά εισαγωγικά. Το δεκαδικό σημείο είναι το κόμμα: `123,27` χωρίς κενό είναι αριθμός, ενώ `α, β` με κενό είναι δύο τιμές (δική μας σύμβαση, γιατί η θεωρία δεν λύνει τη σύγκρουση). Η τελεία βγάζει μήνυμα.
- Γίνονται δεκτά τα `Αρχή_επανάληψης … Μέχρις_ότου` (Γ΄) και `Επανάλαβε … Μέχρις_ότου` (Β΄), το `Αν … τότε εντολή` σε μία γραμμή και το `Επίλεξε` (Γ΄). Επειδή η εφαρμογή δεν επιλέγει τάξη για την ψευδογλώσσα, το `Επίλεξε` παραμένει διαθέσιμο αλλά εμφανίζει προειδοποίηση `P_OUT_OF_CURRICULUM` για μαθητές Β΄ Λυκείου.
- Η προειδοποίηση `W_PSEUDO_STRING_ALPHABET` ελέγχει μόνο αλφαριθμητικές συγκρίσεις των οποίων οι τιμές μπορούν να προσδιοριστούν στατικά. Δεν εγγυάται έλεγχο τιμών που προέρχονται από είσοδο ή άλλη δυναμική εκτέλεση.
- Κάθε συνθήκη περιέχει τουλάχιστον έναν τελεστή σύγκρισης.
- Οι τελεσταίοι των `div` / `mod` είναι θετικοί ακέραιοι (και το 0 ως διαιρετέος δίνει λάθος).
- `ΛΟΓ` είναι ο δεκαδικός και `ΛΝ` ο φυσικός λογάριθμος.
- Με βήμα 0 το `Για` δεν εκτελείται (αρχική τιμή μεγαλύτερη της τελικής) ή γίνεται ατέρμων.
- Ο πρώτος αλγόριθμος του κώδικα είναι ο κύριος· τα Δεδομένα του ζητούνται πριν ξεκινήσει (για πίνακα, τιμές χωρισμένες με κενό ή «κόμμα και κενό», γραμμές με «;») και τα Αποτελέσματά του εμφανίζονται στο τέλος.
- `Κάλεσε Όνομα(…)`: τα ορίσματα αντιστοιχίζονται με τη σειρά πρώτα στα Δεδομένα και μετά στα Αποτελέσματα του αλγορίθμου· μια μεταβλητή που υπάρχει και στις δύο λίστες μετρά δύο φορές. Οι αλγόριθμοι δεν καλούνται μέσα σε εκφράσεις.
- Λέξη στην αρχή γραμμής που απέχει ένα γράμμα από εντολή θεωρείται ορθογραφικό λάθος· αλλιώς ελεύθερη διατύπωση, που δεν εκτελείται.

**Στοίβα και ουρά (απεικόνιση στη «Μνήμη»)**
- Ακολουθείται η υλοποίηση με μονοδιάστατο πίνακα του Συμπληρωματικού υλικού της Γ΄. Στοίβα: `top` με αρχική τιμή 0 για άδεια στοίβα· ώθηση με `top ← top + 1` και μετά αποθήκευση, απώθηση με εξαγωγή από τη θέση `top` και μετά `top ← top - 1`. Ουρά: `front` και `rear` με αρχική τιμή 0 για άδεια ουρά· με την πρώτη εισαγωγή γίνονται και οι δύο 1, και όταν εξαχθεί το τελευταίο στοιχείο (`front = rear`) γίνονται ξανά 0. Τα παραδείγματα «Στοίβα» και «Ουρά» (ΓΛΩΣΣΑ) και «Ουρά εξυπηρέτησης» (ψευδογλώσσα) ακολουθούν αυτή τη λογική.
- Στην ουρά εμφανίζονται ως στοιχεία οι θέσεις από `front` (τουλάχιστον 1) έως `rear`.
- Η αυτόματη αναγνώριση γίνεται όταν το υποπρόγραμμα/ο αλγόριθμος έχει έναν μόνο μονοδιάστατο πίνακα και μεταβλητές με τα ονόματα της θεωρίας (`top`/`κορυφή`, `front`/`εμπρός`, `rear`/`πίσω`). Σε κάθε άλλη περίπτωση η απεικόνιση και οι δείκτες επιλέγονται από την κεφαλίδα του πίνακα. Η αναγνώριση είναι σχεδιαστική επιλογή του GlossaLab.
- Η ένδειξη «γεμάτη» εμφανίζεται μόνο όταν ο πίνακας έχει δηλωμένο μέγεθος (ΓΛΩΣΣΑ). Στην ψευδογλώσσα ο πίνακας δεν έχει μέγεθος, οπότε το όριο το ελέγχει ο ίδιος ο αλγόριθμος (π.χ. με μια μεταβλητή χωρητικότητας).

**Είσοδος**
- Το `ΔΙΑΒΑΣΕ`/`Διάβασε` ζητά τιμή κατά την εκτέλεση. Αν έχουν γραφτεί τιμές στα «Δεδομένα εισόδου», τις παίρνει πρώτα από εκεί και το σημειώνει στην έξοδο. Στην είσοδο του χρήστη ο δεκαδικός γράφεται με τελεία ή κόμμα.
- Αρχεία: `.glo` για ΓΛΩΣΣΑ, `.alg` για ψευδογλώσσα (απλό κείμενο UTF-8). Κατά το άνοιγμα η γλώσσα αναγνωρίζεται από την πρώτη λέξη.

### English summary

GlossaLab is an educational, browser-only interpreter for **ΓΛΩΣΣΑ** and the Greek school **pseudocode** (ψευδογλώσσα), both taught in Greek upper secondary schools. It offers step-by-step execution with breakpoints, plain-language explanations of every step, memory/loop/call-stack visualisation, a trace table, autocomplete, and detailed, student-oriented error messages. Live at [vle.cited.gr/apps/glossa-lab](https://vle.cited.gr/apps/glossa-lab/). Build with `npm install && npm run build`; the result is a self-contained `dist/index.html` (plus icons and a web manifest) that makes no external requests. Created by Athanasios-Antonios Georgalas ([vle.cited.gr](https://vle.cited.gr)), released under the [MIT License](LICENSE).
